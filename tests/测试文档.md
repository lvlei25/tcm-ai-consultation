# 中医 AI 问诊平台测试文档

对应 spec：spec-001-中医AI问诊平台搭建.md 之「测试」章节。

## 运行方式

```bash
cd k:\douyin_assistant\douyin_assiatan
python -m pytest tests/ -v
```

## 覆盖范围

| 模块 | 测试文件 | 覆盖点 |
|------|----------|--------|
| config 配置加载 | tests/test_config.py | .env 解析、注释与空行、API Key 缺失/为空/正常 |
| kb.loader 加载分块 | tests/test_loader.py | 标题切分与元数据、无标题文件、空目录、非 MD 忽略、BOM、超长切分、元数据保留 |
| kb.retriever 混合检索 | tests/test_retriever.py | 权重融合、双路命中、去重、top_k、归一化除零、零分过滤、真实 BM25、k 截断 |
| pipeline 问诊单整理与诊断 | tests/test_pipeline.py | 主诉校验、检索词消息构造、中文无乱码、证据编号与出处、空证据、诊断消息结构 |

## 端到端验证（需 API Key 与知识库）

以下路径依赖真实 DashScope 服务，在单元测试之外按 spec-001「验证」章节手工执行：

1. 放入 MD 医案后运行 `python scripts/build_kb.py`，确认产物生成
2. `.env` 填入 `DASHSCOPE_API_KEY`，启动 `streamlit run app.py`
3. 填写问诊单点击「开始诊断」，确认：检索词生成 → 混合检索 → 流式诊断输出 → 参考医案来源展示
