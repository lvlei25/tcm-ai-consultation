# spec-003：诊断流程分步可视化展示

对应基线：spec-001-中医AI问诊平台搭建.md

## 变更原因

用户希望看到诊断流程每一步执行是否正确。原实现仅用两个 spinner 过渡，中间产物（检索语句、检索明细）不可见。

## 变更内容

| 文件 | 变更 |
|------|------|
| app.py | 诊断区域由 spinner 改为三个 st.status 分步容器：步骤 1/3 生成检索语句（完成显示检索语句原文）、步骤 2/3 混合检索医案（完成显示编号/出处/标题层级/向量分/关键词分/融合分明细表）、步骤 3/3 生成诊断结果（容器内流式输出，完成后保留展开）。每步成功打勾收起，失败标红并 st.stop 中断流程 |
| app.py | render_evidences 参考医案来源增加向量分/关键词分明细 |
| kb/retriever.py | retrieve() 返回项新增 vec_score / bm25_score 两路归一化得分明细，融合分 score 计算逻辑不变 |
| tests/test_retriever.py | 用例 16 增加两路明细分断言 |

## 展示效果

- 步骤 1 完成：显示大模型生成的检索语句
- 步骤 2 完成：显示命中片段明细表（向量分 + 关键词分 + 融合分，可核对 0.6/0.4 加权是否正确）
- 步骤 3 完成：诊断结果流式渲染并保留
- 任一步骤异常：该步标红显示错误原文，后续步骤不执行

## 验证

- pytest 全量通过（32 例）
- 浏览器实测：三步状态依次完成打勾，检索明细表可见，诊断结果完整
