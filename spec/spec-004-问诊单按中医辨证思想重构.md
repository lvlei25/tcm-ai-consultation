# spec-004：问诊单按中医辨证思想重构

对应基线：spec-001-中医AI问诊平台搭建.md

## 变更原因

用户反馈问诊界面过于简单，要求按中医辨证思想修改。原问诊单仅 13 个字段，缺乏舌脉、寒热汗出、情志等辨证关键信息。

## 设计依据

- 四诊：望（面色、舌质、舌苔）、闻（并入情志问诊）、问（十问歌：寒热、汗、头身、饮食、口渴、睡眠、二便、经带、旧病、因）、切（脉象选填，在线场景患者难以自诊）
- 辨证框架：八纲（表里寒热虚实阴阳）、脏腑、气血津液

## 变更内容

| 文件 | 变更 |
|------|------|
| app.py | 问诊单重构为 7 组：基本信息（姓名/性别/年龄/病程）、望诊与切诊（面色/舌质/舌苔/脉象）、问寒热汗出（寒热/汗出）、问头身胸腹（pills：头晕/头痛/胸闷/心悸/胁胀/脘腹胀满/腰膝酸软/身重困倦/关节酸痛）、问饮食口味（饮食/口渴/口味）、问睡眠情志（睡眠/情志）、问二便与经期（大便/小便/经期）。自由文本输入（舌象/寒热）改为结构化下拉选择，降低填写门槛；form_dict 相应重构（望诊为嵌套字典，新增汗出/头身胸腹不适/口渴/口味/情志/经期/脉象等键） |
| pipeline/form_query.py | 检索词生成提示词同步更新字段范围 |
| pipeline/diagnoser.py | 辨证分析要求从八纲、脏腑、气血津液角度分析；证型诊断要求标注八纲属性 |

## 验证

- py_compile 通过，pytest 32 例通过
- 浏览器实测新表单分组渲染、字段齐全、全流程诊断正常
- AppTest 断言 8 个分组标题全部存在（基本信息/望诊与切诊/问寒热与汗出/问头身胸腹/问饮食口味/问睡眠情志/问二便与经期/其他伴随症状），无运行异常
